#### Ansible Template for API Development

Этот шаблон предназначен для автоматизации развертывания и управления серверами вашего API-приложения. Он позволяет описывать инфраструктуру кодом и выполнять операции без ручного входа на серверы.

###### Структура

- `ansible.cfg` — конфигурация Ansible.
- `inventory/` — списки хостов и переменные для окружений (production, staging).
- `playbooks/` — сценарии (плейбуки) для настройки и развертывания.
- `roles/` — переиспользуемые роли (nginx, nodejs, postgresql и т.д.).
- `requirements.yml` — зависимости ролей из Ansible Galaxy.

##### Предварительные требования

- Установленный Ansible на вашей локальной машине (или CI).
- SSH-доступ к серверам (ключи или пароль).
- Python на целевых серверах (обычно уже есть, но для Ubuntu/Debian можно установить).

#### Настройка

1. Скопируйте шаблон в свой проект.
2. Отредактируйте `inventory/<окружение>/hosts.yml`, указав IP-адреса ваших серверов.
3. В `inventory/<окружение>/group_vars/all.yml` задайте общие переменные (имя приложения, домен и т.п.).
4. При необходимости добавьте или измените роли в `roles/`.
5. Настройте `ansible.cfg` под ваш SSH-ключ и пользователя.

### Проверка подключения

```bash
ansible all -m ping
```
